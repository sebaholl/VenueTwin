# Source-aware architectural details

The National Theatre study uses a specialised, photo-informed script. The general Pilot builder now has a separate reusable detail layer: framed panels, open portals/stage surrounds, ceiling coffers, faceted columns and curved balcony fascias. This is a foundation for visually closer reconstructions, not automatic near-identical reconstruction of any venue.

## Use it

1. Save plans, interior photos and measurements under Project → Materials.
2. Analyse and review findings in Pilot. Use **Complete the architecture** and identify which surfaces and features should be reconstructed.
3. Supply component dimensions and positions where known. For interpreted decorative proportions and material appearance, explicitly allow labelled estimates. Pilot must retain a source explanation per component.
4. Review the proposal, apply, then inspect in Studio. Layout → Room → **Architectural details** lists components, dimensions, evidence and removal controls.
5. Build with the general local Blender action. Both live Studio and the general JSON export use the same component geometry and material values. Inspect several seat views and compare proportions against the source images.
6. Rebuild after editing. Detail changes invalidate a loaded model's geometry signature. Exported viewer manifests retain the detail configuration; the model GLB contains generated geometry and materials.

The specific National Theatre detailed exporter stays separate: it cannot combine these components with its own specialised scene. The UI disables that export when generic details are present.

## Modelling contract

All dimensions are metres. X/Z give the world centre (arc centre for a curved wall); bottom is the lowest elevation; rotation is Y-axis degrees. Details are independent of the rectangular room. Moving/removing the room leaves them in place.

| Component | Geometry and orientation |
| --- | --- |
| Panel | Rectangular backing and raised border, facing local negative Z. Width/height/depth describe the backing; trim protrudes in front. |
| Portal | Two jambs and a lintel; open centre. Width/height are outer bounds, trim sets jamb/lintel width. Trim also protrudes in front. |
| Coffered ceiling piece | Rectangular recessed cell, open underneath. Width and depth span the ceiling; height is recess depth. Hidden in overview, visible in seat view. Place multiple components for a grid. |
| Column | Faceted circular shaft with rectangular top/base capitals; shaft diameter is min(width,depth) minus twice trim. Not a fluted/sculpted classical column. |
| Curved wall / fascia | Segmented arc with top/bottom trim. Radius is centreline radius, span is degrees centred on local positive Z. Depth is thickness, height is fascia height. Width is retained in the common record but unused by this geometry. |

Each component has separate main/trim colours, roughness and metalness (0–1). Material appearance inferred from photos remains an estimate. No textures, paintings, arbitrary mesh generation, or online asset downloads are introduced.

Pilot actions are `save_architectural_detail` (upsert by ID) and `remove_architectural_detail` (existing ID only). The action evidence is copied into the saved component. Estimates remain blocked unless allowed. There are at most 40 components, 1,400 generated detail boxes, and 2,000 boxes in the full Blender export. Columns/arcs use 8–48 segments; begin with 12–24 to keep models practical. Invalid dimensions, trim, surfaces and excessive geometry are rejected before rendering.

## Fidelity and validation

Shared geometry and material tests check transformations, open shapes, budgets, evidence, model invalidation and Studio/Blender blueprint equality. Python tests validate material ranges without requiring Blender. These do not establish photorealism or source accuracy; a live Blender render and comparison with the customer's photos are still required.

High-fidelity reconstruction additionally needs registered multi-view references, measured irregular geometry, custom meshes, textures and lighting. Ornate sculpture, painted ceilings, accurate fluting, fabrics, curved room shells and detailed seat upholstery are not generated by this layer. The specialised National Theatre scene is a visual benchmark, not evidence that the generic pipeline reproduces all its detail automatically.
